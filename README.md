# Wave Dynamics on the Critical Möbius Strip

Manuscript by Zheng Yan, April 2026.

## Abstract

We investigate Hodge-harmonic 1-forms on the Schwartz critical Möbius 
strip. The exact non-uniform Gaussian curvature induces a substantial 
spectral collapse from the thin-strip asymptotic value to an effective 
eigenvalue λ_eff ≈ 20.734, and a stability threshold r* ≈ 2.704 below 
which the lowest mode N=1 becomes unavailable; the Schwartz embedding 
r=√3 lies in this regime, and we work with the N=3 mode. We further 
show that the non-uniform effective propagation speed produces a 
non-zero phase delay across the geometric folds, breaking node-antinode 
symmetry. Finally, integrating the Born amplitude of the N=3 mode on 
the orientable double cover yields six complex amplitudes that, as an 
abstract root system in the plane, form a copy of the A_2 root system 
underlying su(3). The construction yields the root locations of A_2 
but does not, by itself, recover the full Lie-algebraic structure.
